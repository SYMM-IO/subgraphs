# Affiliate Aggregate Analytics Models

This document describes the affiliate-level aggregate analytics models added under `perps/analytics/schema.graphql`.

The models roll up account balances, open withdrawal amounts, provider debt fields, and hierarchy health flags at affiliate + deployment level. They store raw indexed components only and do not publish a derived balance formula or policy decision.

Initial validation targets are HyperEVM and Arbitrum analytics deployments. Arbitrum switches to the full `symmio_0_8_6` release source, while HyperEVM keeps its deployed core version and stage-specific routing. Provider contracts are indexed through a dynamic template created from the registration event.

## Account Universe

An account belongs to an affiliate rollup through `Account.accountSource`.

| Account type                   | How it enters the affiliate universe                                                                                   | Bucket               |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------- | -------------------- |
| Legacy MultiAccount account    | Created by `symmioMultiAccount.AddAccount`; `accountSource` is the legacy MultiAccount contract.                       | `LEGACY`             |
| AccountLayer subaccount        | Created by `SubAccountCreated`; `accountSource` is the affiliate emitted by AccountLayer.                              | `SUB_ACCOUNT`        |
| Imported legacy account        | Legacy account moved into AccountLayer by `LegacyAccountImported`; `accountSource` becomes the AccountLayer affiliate. | `IMPORTED_LEGACY`    |
| Custom subaccount              | AccountLayer subaccount whose routing mode is `CUSTOM` or isolation type is `3`.                                       | `CUSTOM_SUB_ACCOUNT` |
| Virtual account                | Created or reused by AccountLayer VA events; inherits the parent subaccount affiliate.                                 | `VIRTUAL_ACCOUNT`    |
| Known but unclassified account | Has source and affiliate, but the subgraph cannot classify the account kind.                                           | `UNKNOWN`            |

Accounts with known source and affiliate but incomplete hierarchy or classification data are still counted in the aggregate and flagged. Accounts missing the source or affiliate needed to place them in an affiliate + deployment row are excluded from that row.

## Population Flow

The aggregate is maintained incrementally by account lifecycle, balance, and withdrawal events.

| Flow                                 | Trigger                                                                                                                | What gets updated                                                                                                                                                                                 |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Legacy MultiAccount account creation | `symmioMultiAccount.AddAccount`                                                                                        | Creates/updates `Account`, stores core deployment profile refs, then creates an `AffiliateExpressWithdrawAccountSnapshot`.                                                                        |
| AccountLayer subaccount creation     | `SubAccountCreated`                                                                                                    | Creates a subaccount snapshot and applies its account-count delta into the affiliate aggregate and bucket.                                                                                        |
| Legacy import into AccountLayer      | `LegacyAccountImported`                                                                                                | Removes the old legacy snapshot, rewrites account membership, adds the imported snapshot, and reclassifies active pending withdrawals.                                                            |
| Virtual account lifecycle            | `VirtualAccountCreated`, `VirtualAccountReused`, `VirtualAccountDeleted`                                               | Adds, moves, or removes VA snapshots. Reuse/deletion also reclassifies active pending withdrawals for that account.                                                                               |
| Subaccount ownership transfer        | `SubAccountOwnershipTransferred`                                                                                       | Rewrites the owner across the complete subaccount/virtual-account hierarchy and refreshes each aggregate membership snapshot.                                                                     |
| Custom routing changes               | `SingleVAModeChanged`                                                                                                  | Recomputes the subaccount bucket, for example `SUB_ACCOUNT` vs `CUSTOM_SUB_ACCOUNT`, and reclassifies active pending withdrawals.                                                                 |
| Account deletion                     | `SubAccountDeleted`, `VirtualAccountDeleted`                                                                           | Removes the snapshot from aggregate/bucket counts and clears or moves active pending-withdrawal aggregate refs.                                                                                   |
| PartyA balance refresh               | `updatePartyALatestBalance`                                                                                            | Reads current PartyA balance components from the core contract and applies a snapshot delta into aggregate and bucket rows.                                                                       |
| Withdrawal initiation                | `WithdrawInitiated`                                                                                                    | Creates `WithdrawRequest`, splits the amount into raw provider categories, stores aggregate refs, adds pending-withdrawal deltas, and indexes the request by account.                             |
| Withdrawal terminal state            | `WithdrawFinalized`, `WithdrawCancelled`, immediate `WithdrawCancelRequested`, `WithdrawRejected`, `WithdrawSuspended` | Subtracts pending-withdrawal deltas using the request's stored component refs, then removes lookup entries.                                                                                       |
| Provider registration                | `RegisterExpressProvider` from `symmio_0_8_6`                                                                          | Stores provider-to-core metadata in `ExpressProviderSource`, creates the dynamic provider template, and marks debt data available for the source once aggregate rows are touched.                 |
| Provider withdrawal lifecycle        | `WithdrawAccepted`, `WithdrawAccelerated`, `WithdrawProcessed`, `WithdrawUnlockedAndProcessed`                         | Records provider acceptance, acceleration amounts, and provider-side processing metadata. Provider processing does not close the core request; only a core terminal event removes pending totals. |
| Advanced withdrawal                  | `WithdrawAdvanced` from `symmio_0_8_6`                                                                                 | Finds the open `WithdrawRequest`, increments `WithdrawRequest.advancedAmount`, and applies the same delta to `advancedWithdrawAmountCollateral` on the aggregate and bucket rows.                 |
| Provider debt                        | Dynamic provider-template events                                                                                       | Populates raw reserved, active, and bad debt fields from `DebtReserved`, `DebtActivated`, `DebtSettled`, `DebtCancelled`, `BadDebtAccrued`, `RequestDebtCleared`, and `CreditBadDebtRepaid`.      |

## Shared Rules

| Concept                   | Rule                                                                                                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aggregate id              | `source-affiliate-collateral`, using lower-case hex strings from `toHexString()`.                                                                                                                                |
| Bucket id                 | `componentsId-bucket`.                                                                                                                                                                                           |
| Account snapshot id       | `account-source`.                                                                                                                                                                                                |
| Source                    | Balance and withdrawal events pass the Symmio core event source. Membership-only events use `Account.coreSource` first, then `Account.source`. Legacy MultiAccount creation stores core profile refs explicitly. |
| Affiliate                 | Always `Account.accountSource`. If this is missing, the account cannot be placed into an affiliate aggregate.                                                                                                    |
| Collateral                | `Configuration.collateral`; if config is missing, the helper falls back to the zero address.                                                                                                                     |
| Bucket                    | Derived from `Account.accountKind`, `SubAccount.isLegacy`, `SubAccount.routingMode`, and `SubAccount.isolationType`.                                                                                             |
| Balance units             | Fields ending in `18` are Symmio 18-decimal accounting units from core balance reads.                                                                                                                            |
| Withdrawal units          | Fields ending in `Collateral` are raw collateral-token decimals from withdrawal events.                                                                                                                          |
| Negative count protection | Count fields use non-negative add helpers so removals cannot push counts below zero. Amount fields apply exact signed deltas.                                                                                    |

## `AffiliateExpressWithdrawComponents`

One aggregate row for one affiliate, one Symmio deployment source, and one collateral.

| Field                                    | Meaning                                                                                                          | How it is populated                                                                                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                     | Deterministic aggregate id.                                                                                      | Built as `source-affiliate-collateral`.                                                                                                                         |
| `deploymentId`                           | Human-readable deployment id when known.                                                                         | `deploymentForSource(source, account)` prefers `Account.deploymentId`, otherwise uses the static source map.                                                    |
| `source`                                 | Canonical Symmio core address for this deployment.                                                               | Set from the core event source passed into `loadComponents()`.                                                                                                  |
| `coreSource`                             | Same canonical core address, kept for profile-query consistency.                                                 | Set to `source` when the component row is created.                                                                                                              |
| `accountLayerSource`                     | AccountLayer address for this deployment when known.                                                             | `accountLayerForSource(source, account)` prefers `Account.accountLayerSource`, otherwise uses the static core-to-layer map.                                     |
| `affiliate`                              | Affiliate/account-source address for the rollup.                                                                 | Set from `Account.accountSource` at snapshot or withdrawal classification time.                                                                                 |
| `collateral`                             | Collateral token address for the current deployment config.                                                      | Loaded from `Configuration.collateral`; zero address fallback if configuration is missing.                                                                      |
| `collateralDecimals`                     | Collateral decimals metadata.                                                                                    | Currently initialized to `0`; analytics does not index ERC20 metadata.                                                                                          |
| `accountCount`                           | Number of accounts currently included in this affiliate universe.                                                | Incremented when a snapshot is added and decremented when a snapshot is removed or reclassified out.                                                            |
| `accountWithBalanceCount`                | Accounts with a non-zero PartyA balance snapshot.                                                                | Incremented when `LatestAccountBalance` exists and contributes non-zero fields; decremented when the balance snapshot is cleared or removed.                    |
| `freeBalance18`                          | Sum of current PartyA free balances.                                                                             | Delta from `LatestAccountBalance.freeBalance`, populated by `getBalanceOf()` inside `updatePartyALatestBalance`.                                                |
| `allocatedBalance18`                     | Sum of current PartyA allocated margin.                                                                          | Delta from `LatestAccountBalance.allocatedBalance`, populated from `getBalanceInfoOfPartyA.value0`.                                                             |
| `lockedCva18`                            | Sum of locked CVA.                                                                                               | Delta from `LatestAccountBalance.lockedCva`, populated from `getBalanceInfoOfPartyA.value1`.                                                                    |
| `lockedLf18`                             | Sum of locked liquidation fee.                                                                                   | Delta from `LatestAccountBalance.lockedLf`, populated from `getBalanceInfoOfPartyA.value2`.                                                                     |
| `lockedPartyAmm18`                       | Sum of locked PartyA maintenance margin.                                                                         | Delta from `LatestAccountBalance.lockedPartyAmm`, populated from `getBalanceInfoOfPartyA.value3`.                                                               |
| `lockedPartyBmm18`                       | Sum of locked PartyB maintenance margin attributed to PartyA.                                                    | Delta from `LatestAccountBalance.lockedPartyBmm`, populated from `getBalanceInfoOfPartyA.value4`.                                                               |
| `pendingLockedCva18`                     | Sum of pending locked CVA.                                                                                       | Delta from `LatestAccountBalance.pendingLockedCva`, populated from `getBalanceInfoOfPartyA.value5`.                                                             |
| `pendingLockedLf18`                      | Sum of pending locked liquidation fee.                                                                           | Delta from `LatestAccountBalance.pendingLockedLf`, populated from `getBalanceInfoOfPartyA.value6`.                                                              |
| `pendingLockedPartyAmm18`                | Sum of pending locked PartyA maintenance margin.                                                                 | Delta from `LatestAccountBalance.pendingLockedPartyAmm`, populated from `getBalanceInfoOfPartyA.value7`.                                                        |
| `pendingLockedPartyBmm18`                | Sum of pending locked PartyB maintenance margin attributed to PartyA.                                            | Delta from `LatestAccountBalance.pendingLockedPartyBmm`, populated from `getBalanceInfoOfPartyA.value8`.                                                        |
| `totalBalance18`                         | Total free plus allocated PartyA collateral.                                                                     | Delta from `LatestAccountBalance.totalBalance`; locked and pending-locked values are excluded because they are already backed by allocated balance.             |
| `pendingWithdrawAmountCollateral`        | Total open withdrawal amount in collateral decimals.                                                             | Added on `WithdrawInitiated` as the sum of all provider categories. Removed on terminal events using stored component refs.                                     |
| `pendingClassicWithdrawAmountCollateral` | Open withdrawal amount without provider routing.                                                                 | Sum of initiated parts where both provider addresses are zero.                                                                                                  |
| `pendingExpressWithdrawAmountCollateral` | Open withdrawal amount routed through the non-virtual provider path.                                             | Sum of initiated parts where the provider address is non-zero and virtual provider is zero.                                                                     |
| `pendingVirtualWithdrawAmountCollateral` | Open withdrawal amount routed through a virtual provider.                                                        | Sum of initiated parts where virtual provider is non-zero.                                                                                                      |
| `advancedWithdrawAmountCollateral`       | Withdrawal amount already advanced by a provider and still represented in analytics for open request accounting. | Incremented by `WithdrawAdvanced` after resolving the open `WithdrawRequest`; decremented when terminal handlers remove that request's stored component deltas. |
| `advancedWithdrawDataAvailable`          | Whether the advanced-withdraw event path is indexed for this row's source.                                       | Initialized from the source map for HyperEVM and Arbitrum; also set to `true` when a non-zero advanced-withdraw delta is applied.                               |
| `reservedDebtCollateral`                 | Provider reserved debt for this affiliate/source/collateral.                                                     | Increased on `DebtReserved`; decreased on `DebtActivated`, `DebtCancelled`, and non-activated `RequestDebtCleared`. Deltas are clamped at zero on subtraction.  |
| `activeDebtCollateral`                   | Provider active debt for this affiliate/source/collateral.                                                       | Increased on `DebtActivated`; decreased on `DebtSettled` and activated `RequestDebtCleared`. Deltas are clamped at zero on subtraction.                         |
| `badDebtCollateral`                      | Provider bad debt for this affiliate/source/collateral.                                                          | Increased on `BadDebtAccrued`; decreased on `CreditBadDebtRepaid`. Deltas are clamped at zero on subtraction.                                                   |
| `debtDataAvailable`                      | Whether provider debt sources are known for this row's core source.                                              | Initialized to `false`; set to `true` when a provider source is registered for the core or when a debt delta is applied.                                        |
| `brokenHierarchyCount`                   | Count of accounts whose AccountLayer hierarchy could not be resolved.                                            | Snapshot delta count where `brokenHierarchy == true`.                                                                                                           |
| `unresolvedLegacyAccountCount`           | Count of old MultiAccount accounts not imported into AccountLayer.                                               | Snapshot delta count where bucket is `LEGACY`.                                                                                                                  |
| `unknownAccountCount`                    | Count of accounts that can be placed in this row but cannot be classified into a known bucket.                   | Snapshot delta count where bucket is `UNKNOWN`; accounts missing source/affiliate are excluded, not counted here.                                               |
| `lastBalanceTimestamp`                   | Last timestamp when membership or balance snapshot deltas updated the row.                                       | Set by `applySnapshotDelta()` on snapshot add/remove/reclassification/balance refresh.                                                                          |
| `lastWithdrawTimestamp`                  | Last timestamp when pending or advanced withdrawal deltas updated the row.                                       | Set by `applyWithdrawDelta()` on withdrawal initiation, terminal removal, reclassification, or advanced-withdraw updates.                                       |
| `lastDebtTimestamp`                      | Last timestamp when provider debt components changed.                                                            | Set by provider debt event handlers when reserved, active, or bad debt changes.                                                                                 |
| `updateTimestamp`                        | Last aggregate mutation timestamp.                                                                               | Set on every aggregate mutation.                                                                                                                                |
| `blockNumber`                            | Last aggregate mutation block.                                                                                   | Set on every aggregate mutation.                                                                                                                                |

## `AffiliateExpressWithdrawComponentBucket`

| `id`                                     | Deterministic bucket id.                                                      | Built as `componentsId-bucket`.                                                                                                                                        |
| `components`                             | Parent aggregate row.                                                         | Set to `AffiliateExpressWithdrawComponents.id` when the bucket row is created.                                                                                         |
| `deploymentId`                           | Same deployment id as the parent row.                                         | Copied from the parent aggregate on creation.                                                                                                                          |
| `source`                                 | Same core source as the parent row.                                           | Copied from the parent aggregate on creation.                                                                                                                          |
| `coreSource`                             | Same profile core source as the parent row.                                   | Copied from the parent aggregate on creation.                                                                                                                          |
| `accountLayerSource`                     | Same AccountLayer source as the parent row.                                   | Copied from the parent aggregate on creation.                                                                                                                          |

| `pendingLockedPartyBmm18`                | Pending locked PartyB maintenance margin for this bucket.                     | Same `LatestAccountBalance.pendingLockedPartyBmm` deltas as the parent row, scoped to this bucket.                                                                     |

## `AffiliateExpressWithdrawAccountSnapshot`

Per-account delta state used by the subgraph when a balance or account classification changes. The previous snapshot contribution is removed before the new one is added.

| Field                     | Meaning                                                                                                | How it is populated                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `id`                      | Deterministic snapshot id.                                                                             | Built as `account-source`.                                                                                             |
| `components`              | Parent aggregate row.                                                                                  | Set from the resolved `AffiliateExpressWithdrawComponents.id`.                                                         |
| `deploymentId`            | Deployment id for this snapshot.                                                                       | Copied from the parent component row every time `syncSnapshot()` writes the snapshot.                                  |
| `source`                  | Core source used for this account snapshot.                                                            | Resolved by `sourceForAccount(account, fallbackSource)`.                                                               |
| `coreSource`              | Profile core source.                                                                                   | Copied from the parent component row.                                                                                  |
| `accountLayerSource`      | Profile AccountLayer source.                                                                           | Copied from the parent component row.                                                                                  |
| `affiliate`               | Affiliate/account-source address.                                                                      | Copied from the parent component row, originally from `Account.accountSource`.                                         |
| `collateral`              | Collateral token address.                                                                              | Copied from the parent component row.                                                                                  |
| `collateralDecimals`      | Collateral decimals placeholder.                                                                       | Copied from the parent component row, currently `0`.                                                                   |
| `account`                 | Account address represented by this snapshot.                                                          | Set from `Account.account`.                                                                                            |
| `accountRef`              | Link to the indexed `Account`.                                                                         | Set from `Account.id`.                                                                                                 |
| `owner`                   | Account owner/user when known.                                                                         | Set from `Account.owner`.                                                                                              |
| `subAccountRef`           | Subaccount link when the account is a subaccount or VA child.                                          | Set from `Account.subAccount`.                                                                                         |
| `virtualAccountRef`       | Virtual-account link when applicable.                                                                  | Set from `Account.virtualAccount`.                                                                                     |

| `lockedLf18`              | Account-level locked liquidation fee.                                                                  | Copied from `LatestAccountBalance.lockedLf`, preserved on membership-only sync, or zeroed on clear.                    |
| `lockedPartyAmm18`        | Account-level locked PartyA maintenance margin.                                                        | Copied from `LatestAccountBalance.lockedPartyAmm`, preserved on membership-only sync, or zeroed on clear.              |
| `lockedPartyBmm18`        | Account-level locked PartyB maintenance margin.                                                        | Copied from `LatestAccountBalance.lockedPartyBmm`, preserved on membership-only sync, or zeroed on clear.              |
| `pendingLockedCva18`      | Account-level pending locked CVA.                                                                      | Copied from `LatestAccountBalance.pendingLockedCva`, preserved on membership-only sync, or zeroed on clear.            |
| `pendingLockedLf18`       | Account-level pending locked liquidation fee.                                                          | Copied from `LatestAccountBalance.pendingLockedLf`, preserved on membership-only sync, or zeroed on clear.             |
| `pendingLockedPartyAmm18` | Account-level pending locked PartyA maintenance margin.                                                | Copied from `LatestAccountBalance.pendingLockedPartyAmm`, preserved on membership-only sync, or zeroed on clear.       |
| `pendingLockedPartyBmm18` | Account-level pending locked PartyB maintenance margin.                                                | Copied from `LatestAccountBalance.pendingLockedPartyBmm`, preserved on membership-only sync, or zeroed on clear.       |
| `totalBalance18`          | Account-level free plus allocated balance.                                                             | Copied from `LatestAccountBalance.totalBalance`, preserved on membership-only sync, or zeroed on clear.                |
| `brokenHierarchy`         | Whether this account has missing hierarchy links.                                                      | True when a subaccount or virtual-account hierarchy reference is expected but the linked entity is missing.            |
| `unresolvedLegacyAccount` | Whether this account is old MultiAccount legacy.                                                       | True when bucket is `LEGACY` and account kind is legacy MultiAccount.                                                  |
| `unknownAccount`          | Whether this account cannot be classified cleanly after being placed in an affiliate/source aggregate. | True when bucket is `UNKNOWN`. Accounts missing source/affiliate are excluded before this point.                       |

| `blockNumber`             | Last snapshot write block.                                                                             | Set on membership or balance sync.                                                                                     |

If `Account.isDeleted == true` or `Account.accountSource == null`, `syncSnapshot()` removes the previous snapshot, if any, and does not add a new one.

## Added `WithdrawRequest` Fields

These fields let pending-withdrawal deltas be split and later removed safely. Terminal handlers subtract using the stored component refs instead of current account classification, because an account may have moved since the request was initiated.

| Field                 | Meaning                                                                 | How it is populated                                                                                                                                                                            |
| --------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `componentSource`     | Aggregate source that received the pending-withdrawal delta.            | Set on `WithdrawInitiated` from the resolved core source; cleared if the account cannot be safely classified; rewritten during account reclassification.                                       |
| `componentAffiliate`  | Aggregate affiliate that received the pending-withdrawal delta.         | Set from `Account.accountSource`; cleared if missing; rewritten during account reclassification.                                                                                               |
| `componentCollateral` | Aggregate collateral that received the pending-withdrawal delta.        | Set from `Configuration.collateral`; rewritten during account reclassification.                                                                                                                |
| `componentBucket`     | Bucket that received the pending-withdrawal delta.                      | Set from `accountBucket()`; rewritten during account reclassification.                                                                                                                         |
| `classicAmount`       | Portion of request amount without provider routing.                     | Sum of `WithdrawInitiated.parts.amount` where both provider addresses are zero.                                                                                                                |
| `expressAmount`       | Portion of request amount routed through the non-virtual provider path. | Sum of parts where the provider address is non-zero and virtual provider is zero.                                                                                                              |
| `virtualAmount`       | Portion of request amount with virtual provider routing.                | Sum of parts where virtual provider is non-zero.                                                                                                                                               |
| `advancedAmount`      | Portion already advanced by provider.                                   | Initialized to zero on `WithdrawInitiated`; incremented by `WithdrawAdvanced`; removed from aggregate rows when the request reaches a terminal state.                                          |
| `reservedDebtAmount`  | Request-level reserved debt mirror.                                     | Initialized to zero; increased on `DebtReserved`; decreased on `DebtActivated`, `DebtCancelled`, and non-activated `RequestDebtCleared`.                                                       |
| `activeDebtAmount`    | Request-level active debt mirror.                                       | Initialized to zero; increased on `DebtActivated`; decreased on `DebtSettled` and activated `RequestDebtCleared`.                                                                              |
| `badDebtAmount`       | Request-level bad debt mirror.                                          | Initialized to zero; increased on `BadDebtAccrued`. Affiliate-level bad debt repayment is tracked on the aggregate because the repayment event is affiliate-scoped rather than request-scoped. |
| `acceleratedAt`       | Provider acceleration timestamp.                                        | Set by `WithdrawAccelerated`, including through a transaction-scoped pre-init hint.                                                                                                            |
| `acceleration*`       | Raw affiliate, credit-line, and general-pool acceleration values.       | Copied from `WithdrawAccelerated`.                                                                                                                                                             |
| `providerOptionType`  | Raw provider tier: `0` SAME_TX, `1` WINDOWED, or `2` STANDARD.          | Copied from `WithdrawAccepted`, including through a transaction-scoped pre-init hint.                                                                                                          |
| `providerProcessedAt` | Timestamp when the provider completed its processing stage.             | Set by either `WithdrawProcessed` or `WithdrawUnlockedAndProcessed`; this does not change the core request `status`.                                                                           |
| `providerProcessed*`  | Provider processing block, transaction, and event name.                 | Copied from the provider terminal event so provider state remains distinct from core finalization.                                                                                             |

## `WithdrawRequestAccountLookup`

This index lets lifecycle handlers reclassify one account's active pending withdrawals without scanning every withdrawal request in the deployment.

| Field              | Meaning                                                     | How it is populated                                                                                                                                                                   |
| ------------------ | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | Deterministic account lookup id.                            | Built as `account-source`.                                                                                                                                                            |
| `source`           | Core source for the pending request set.                    | Copied from `WithdrawRequest.source`.                                                                                                                                                 |
| `account`          | Account address for the pending request set.                | Copied from `WithdrawRequest.user`.                                                                                                                                                   |
| `activeRequestIds` | Active withdrawal request ids for this account/source pair. | `addWithdrawRequestToLookup()` appends on `WithdrawInitiated`; terminal handlers remove through `removeWithdrawRequestFromLookup()`. The row is removed when the array becomes empty. |

`syncAffiliateExpressWithdrawAccountPendingRequests()` loads this index for the previous and current source of one account, subtracts each active request from its stored component refs, recomputes refs, and re-adds it. This is linear in that account's active withdrawal count, not in total protocol accounts.

## `ExpressProviderWithdrawLifecycleHint`

Transaction-scoped bridge for provider events that are emitted before the core request entity exists. The id combines core, user, request id, and transaction hash. It carries provider acceptance metadata, acceleration, debt, and provider-processing values until `WithdrawInitiated` creates the `WithdrawRequest`; consumption validates every identity component, applies the values once, and removes the hint. Provider processing remains metadata only—the core request stays active until a core terminal event.

## `WithdrawCoreLifecycleHint`

Transaction-scoped bridge for core `WithdrawAccepted`, `WithdrawRejected`, and `WithdrawAdvanced` events emitted by a synchronous provider callback before the outer `WithdrawInitiated` event. It preserves the latest core status and cumulative advanced amount, then `WithdrawInitiated` consumes it after creating the request and pending aggregates. A hinted rejection immediately removes that request from pending accounting and active lookups.

## `ExpressProviderSource`

Provider metadata used by the dynamic provider template and debt handlers.

| Field          | Meaning                                       | How it is populated                                                                                                                      |
| -------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | Deterministic provider metadata id.           | Built as `provider.toHexString()`.                                                                                                       |
| `provider`     | Provider contract address.                    | Set from `RegisterExpressProvider.provider`; if needed later, debt handlers can recover it from the provider event source.               |

| `deploymentId` | Human-readable deployment id when known.      | Resolved from the static source map using the core source address.                                                                       |
| `timestamp`    | Last provider metadata write timestamp.       | Set on registration or fallback metadata recovery.                                                                                       |
| `blockNumber`  | Last provider metadata write block.           | Set on registration or fallback metadata recovery.                                                                                       |

## `ExpressProviderSourceByCore`

Core-scoped marker used to know that a source has provider debt data available without scanning provider metadata rows. Perps-core permits multiple registered providers per core, so this row deliberately contains no singular provider field. Every provider remains available as its own `ExpressProviderSource` row and can be queried by `source`.

| Field          | Meaning                                  | How it is populated                               |
| -------------- | ---------------------------------------- | ------------------------------------------------- |
| `id`           | Deterministic core lookup id.            | Built as `source.toHexString()`.                  |
| `source`       | Symmio core address.                     | Copied from `ExpressProviderSource.source`.       |
| `collateral`   | Collateral token address.                | Copied from `ExpressProviderSource.collateral`.   |
| `deploymentId` | Human-readable deployment id when known. | Copied from `ExpressProviderSource.deploymentId`. |
| `timestamp`    | Last lookup write timestamp.             | Set when provider metadata is written.            |
| `blockNumber`  | Last lookup write block.                 | Set when provider metadata is written.            |
